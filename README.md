# PROJETO ENEM
## Grupo: Alessandro da Silva Moreira, Leon Antonio, Matheus Mendes, Otávio Augusto Di Lorenzo e Yuri Miguel Pinto.
*Projeto com interface GTK e integrado com banco de dados. Atividade do 4º bimestre de LPII.*

---

## Como usar:
> 1. Crie uma pasta na sua IDE e crie/coloque os arquivos lá.
> 2. Crie seu banco no TiDB e crie um arquivo config.ini com todas as informações do banco, igual no config.exemplo.ini nesse repositório.
> 3. Crie ou baixe o arquivo script.sql desse repositório e execute lá no TiDB.
> 4. Faça a mesma coisa com arquivo da interface enem_tela.glade.
> 5. Faça a mesma coisa com o arquivo conexao.py e teste_conexao.py.
> 6. Execute o teste_conexao.py pra ver se tá tudo ok.
> 7. Coloque o arquivo repositorio_enem desse repositório na sua pasta também.
> 8. Por final, coloque enem.py e execute-o.

---

# PARA INSERIR: coloque todas as informações nos campos (menos o ID) e clique no botão para inserir.
# PARA ATUALIZAR: a mesma coisa, mude os campos que quiser atualizar e clique no botão para atualizar.
# PARA DELETAR: somente informar o ID e clicar no botão.
# PARA LER: para uma questão aleatória é somente clicar no botão, para buscar pelo ID, preencha o campo e clique no botão.
